# 2026-10-10 -- Saved results move to drizzle

## Session summary

David asked to use drizzle for the database, and whether the engine needs pi or the Claude Agent
SDK. This session moved the saved-result store to drizzle and answered the runtime question in the
project thread.

## Work completed

- `src/reviews/lib/schema.ts` defines the `chunk_reviews` table with drizzle. `mise run db:generate`
  writes its migrations into `drizzle/`, the same layout as monicandavid.com. The first migration
  replaces `migrations/0001-chunk-reviews.sql`.
- `createSqliteChunkReviewStore` takes a drizzle database. In phase 2, the worker passes
  `drizzle(env.DB)`. Its tests use an in-memory SQLite database (`node:sqlite`) with the real
  migrations applied.

## Decisions

- Use drizzle for D1, the same as monicandavid.com (David asked for it).

## Next steps

- Phase 2, with one proposed change. Keep the direct OpenRouter calls, without pi or the Claude
  Agent SDK. The Claude Agent SDK needs a local filesystem and shell, and a Worker has neither.
- Give each reviewer a small tool loop. Its tools read a file and list a directory through the
  GitHub API, at the PR's head commit. A saved chunk review then records the files its reviewer
  read, and stays valid while the chunk and those files do not change.

## Blockers / open questions

- Whether to add the tool loop in phase 2 or ship chunk-only reviews first (asked in the project
  thread).
