## Decisions made

- Class (`.light`/`.dark`) on `<html>` is the repo-wide DOM contract (Panda default `_dark`,
  Tailwind `@custom-variant`, mode-watcher, and @nuxtjs/color-mode all align on it); djf.io's
  `data-theme` attribute was the outlier and moved.
- Storage key `theme` everywhere (revision.city and djf.io already used it; no saved preference
  orphaned). `system` is stored explicitly; absent/invalid reads as system.
- Svelte and Nuxt use ecosystem libraries configured to the contract instead of hand-rolled code;
  the hand-rolled core exists only where no library fits (React/TanStack, Astro).
- davidjfelix.com stays dark-only (deliberate design; it already declares `color-scheme: dark`).
- mode-watcher's `themeColors` prop is not used (verified bug: system mode picks the dark meta color
  on a light OS).
