# 2026-08-02 progress

Project created from a strategy discussion with David, then rebased onto the bun migration (#397)
and the theme extraction (#396) after both landed on main. Established while writing the plan:

- Before the theme extraction, all twelve apps shared zero code, so the per-app path filters were an
  honest encoding. The extraction is the flip: `packages/theme/**` now appears in 27 workflow files,
  every consumer workflow carries its own `bun install (packages/theme)` step, and the package has
  its own `ci-theme.yml`. That is the by-hand dependency graph this plan replaces.
- Depot docs verified: Depot CI supports `workflow_call`; Depot Cache supports Turborepo natively
  and is described as built into Depot CI with no configuration.
- Turborepo supports bun workspaces and the text `bun.lock` the repo already uses, including
  lockfile-aware hashing; `turbo prune` has known rough edges with bun but is out of scope (no
  Docker pruning here).
- The session-start hook's thirteen sequential `bun install` runs are a visible cost of the
  independent-lockfile layout that phase 1 removes.

Plan written; next step is phase 0 spikes and David's sign-off on the workspace-rule reversal.
