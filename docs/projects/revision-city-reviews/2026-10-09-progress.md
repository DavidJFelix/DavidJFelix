# 2026-10-09 -- Plan agreed, review engine built

## Session summary

Agreed the plan with David in the project thread and built phase 1, the review engine.

## Work completed

- `src/reviews/lib/`: patch parsing, chunking with chunk-local line labels, the three reviewer
  prompts, an OpenRouter client, the saved-result store (D1 and in-memory), and the orchestrator. 45
  unit tests, 100% coverage, inside the app's existing coverage gate.
- `migrations/0001-chunk-reviews.sql` for the result table. Not bound in `wrangler.toml` yet: the
  binding needs a real database ID, which phase 2 creates.
- `mise run review -- owner/repo#123` prints the findings for a PR. A dry run against PR #409
  fetched its files and made 204 chunk reviews (68 chunks, 3 reviewers).

## Decisions

- Webhook-triggered GitHub App, findings as inline review comments, OpenRouter, any installation
  behind an allowlist (David's answers in the thread).
- Cloudflare Workflows plus D1 instead of Queues.
- No in-viewer findings for now (David's call).
